# samples/

Our demo data, generated by `tools/make_samples.py` (`make samples`), one folder per format:

| Folder | What it is |
| --- | --- |
| `libra98/`, `lablog/`, `vault/` | **Stand-ins**: the layout is invented by us; the real formats will differ |
| `wks/` | Lotus 1-2-3 worksheets, built from the real public format |
| `pak/` | Quake PACK archives, built from the real public format |

Each folder has clean files plus a few damaged copies (`<name>.damaged-<what>`). The true
contents of every file are in `../sample-answers/`.

## Real samples

The organisers' files are the **real samples**. They go in `real-samples/<format>/` (git-ignored,
they may be sensitive), never in this folder:

```
real-samples/libra98/  real-samples/lablog/  real-samples/vault/  real-samples/<game_archive>/  real-samples/<realworld>/
```

When they arrive, redo each stand-in spec from the real bytes (`python3 tools/survey.py
real-samples/libra98/`) and run `make run-real`.
